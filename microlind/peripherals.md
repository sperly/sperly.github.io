To make it easier on myself I desided to design the main board with expansion headers for graphics and audio. And for good measure I added in a general expansion port to be able to add whatever to the system.

So the expansions that I have planned is:

* [SID audio board](/microlind/peripherals/sid-board)
* OPL2/3 audio board
* VDC (MOS 8568) graphics board
* Yamaha V9938 graphics (maybe...)
* IO board (8 in, 8 out, analog inputs)
* MIDI interface
* Floppy Disk
